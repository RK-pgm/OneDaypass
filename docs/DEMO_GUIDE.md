# 📱 คู่มือซ้อมเดโม่บนเวที (Stage Demo Walkthrough)

เพื่อให้การนำเสนอราบรื่น ไม่มีสะดุด ไม่เกิดบั๊กกะทันหันบนเวที ให้ปฏิบัติตามลำดับขั้นตอนนี้:

---

## ขั้นตอนที่ 0: เตรียมพร้อมก่อนขึ้นเวที (Pre-flight Check)
1. เปิด Terminal รัน Backend ไว้:
   ```powershell
   cd C:\Users\IT-Service\.gemini\antigravity-ide\scratch\daypass\backend
   npm run dev
   ```
2. เปิด Terminal รัน Frontend:
   ```powershell
   cd C:\Users\IT-Service\.gemini\antigravity-ide\scratch\daypass\frontend
   npm run dev
   ```
3. เปิดเบราว์เซอร์ไปที่ [http://localhost:5173/](http://localhost:5173/)
4. ปรับขนาดหน้าจอเป็น **Mobile View** (กด F12 -> Toggle Device Toolbar -> เลือก iPhone 14 Pro หรือหน้าจอมือถือ)

---

## ขั้นตอนที่ 1: หน้าแรก (Home & Customizer)
- ชี้ให้กรรมการเห็น Header และตัวเลือก Preset ด้านบน
- กดคลิกที่ปุ่ม **"☕ สโลว์ไลฟ์"** สไลเดอร์งบประมาณจะปรับเป็น ฿450 อัตโนมัติ
- ลองเลื่อนสไลเดอร์งบให้ดูว่า responsive ลื่นไหล
- กดปุ่ม **"ดูบนแผนที่"** เพื่อแสดงแผนที่ Leaflet ในย่านตลาดน้อย พร้อมหมุดร้านค้าสีสดใส
- กดปุ่มใหญ่สีน้ำเงิน **"สร้างแผนเที่ยววันนี้ทันที"**

---

## ขั้นตอนที่ 2: หน้าแผนเที่ยว (Plan Preview `/plan`)
- โชว์ให้เห็นว่าระบบเรียงไทม์ไลน์เวลาจริง (เช่น 10:00 น., 11:30 น.)
- สลับปุ่มมุมขวาบนระหว่าง **"ไทม์ไลน์"** และ **"แผนที่เส้นทาง"** เพื่อโชว์เส้น Polyline เชื่อมต่อจุดเที่ยว
- ชี้ให้เห็นป้ายเขียว **🎟️ มีคูปองอาหาร** และป้ายเหลือง **📸 มิชชั่นล่าแต้ม**
- ชี้ให้เห็นราคาพาสเพียง ฿199 เทียบกับงบที่ต้องจ่ายแยกจริง
- กดปุ่มสีส้มด้านล่าง **"ซื้อ DayPass นี้"**

---

## ขั้นตอนที่ 3: หน้าชำระเงิน (Checkout `/checkout`)
- โชว์ **PromptPay QR Code จริง** ที่สร้างขึ้นแบบ Real-time ตามยอดเงิน
- แสดงสไลเดอร์การใช้แต้มสะสมลดราคา (1 แต้ม = 2 บาท สูงสุด 30%)
- กดปุ่มสีเขียว **"ฉันโอนเงินแล้ว (ออกพาสทันที)"**
- พลุเฉลิมฉลอง (Confetti) จะยิงขึ้นบนหน้าจอ และระบบจะพาไปยังหน้าบัตร DayPass ทันที!

---

## ขั้นตอนที่ 4: หน้าบัตรท่องเที่ยว (Active DayPass `/pass/...`)
- ชี้ให้เห็น **รหัสพาส (เช่น DP-62LJR)** และสถานะ **Active Pass**
- กดปุ่ม **"แสดง QR พาสหน้าร้าน"** จะมีป๊อปอัป QR ตั๋วขนาดใหญ่สำหรับสแกนหน้าร้าน
- **การสาธิตเช็กอิน (Tab แผนเที่ยว)**:
  - สังเกตแถบด้านบน **"โหมดจำลองสำหรับกรรมการ"** เปิดอยู่
  - กดปุ่ม **"กดเช็กอินที่ร้าน"** ที่จุดแรก
  - จะมีพลุขึ้นและสถานะเปลี่ยนเป็น **"เช็กอินสำเร็จแล้ว"** พร้อมระยะทางจำลอง 25 ม.
- **การสาธิตคูปอง (Tab คูปองอาหาร)**:
  - สลับไปแท็บคูปอง จะเห็นคูปองอาหาร 2-3 ใบ
  - กดปุ่ม **"กดใช้สิทธิ์"** บนคูปองใบแรก
  - จะมี Modal เด้งขึ้นมาเตือนว่าให้พนักงานร้านกด
  - กดปุ่ม **"พนักงานกดยืนยัน"** -> คูปองจะเปลี่ยนสถานะเป็น **"ใช้งานแล้ว"** ทันที (และกดใช้ซ้ำไม่ได้)
- **การสาธิตมิชชั่นสะสมแต้ม (Tab มิชชั่นแต้ม)**:
  - สลับไปแท็บมิชชั่น จะเห็นว่าร้านที่เราเช็กอินแล้ว ปลดล็อกปุ่ม **"ส่งรูปภารกิจ"** แล้ว
  - กดปุ่ม **"ส่งรูปภารกิจ"** -> เลือกรูปหรือกด **"จำลองส่งรูป (+5 แต้ม)"**
  - แต้มสะสมจะเพิ่มขึ้นทันที!
- **การสาธิตกระเป๋าแต้ม (Wallet Modal)**:
  - กดที่ปุ่ม **แต้มสะสม** มุมขวาล่าง หรือกล่องแต้มใน Navbar
  - จะเปิดกระเป๋าเงินโชว์แต้มและมูลค่าส่วนลดเป็นเงินบาทสำหรับซื้อพาสครั้งต่อไป

---

## ขั้นตอนที่ 5: หน้าต่าง Pitch Biz สำหรับตอบคำถามกรรมการ
- หากกรรมการถามเรื่อง Business Model ให้คลิกปุ่ม **"Pitch Biz"** มุมขวาบนของ Navbar
- จะแสดง 3 เสาหลักรายได้และวงจร Flywheel ชัดเจนบนหน้าจอ
